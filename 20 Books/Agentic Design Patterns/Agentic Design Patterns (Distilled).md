# Intro to Agents 
- complexity of agents & agentic system design = need for design patterns
	- not rigid rules, but battle-tested blueprints to standard design/implementation challenges
- context engineering
	- short + focused + powerful context = achieve best accuracy w agents
	- <mark style="background: #FFB8EBA6;">context engineering</mark> = discipline of strategically selecting, packaging + managing most critical info for the agent
- hypotheses for future of agents
	- emergence of a generalist agent 
	- rise of SLMs
	- deep personalisation + proactive goal discovery
	- agents as particpants in the economy 
	- agents will carry out more of the task, less hand holding
