# AI can code, but it can't build software

<div align="center">
  <img src="https://news.ycombinator.com/y18.svg" width="220" />
</div>

Source: https://bytesauna.com/post/coding-vs-software-engineering

Exported at: `2026-01-10T05:19:50Z`

- The thing is that **AI can code, but it can't build software**
- There is old wisdom that says: *Coding is easy, software engineering is hard.* It seems fair enough to say that LLMs are already able to automate a lot of coding. GPT-5 and the like solve isolated well-defined problems with a pretty nice success rate. Coding, however, is not what most people are getting paid for. Building a production-ready app is not coding, it’s software engineering.
- The average production software only does a bunch of easy things. The challenge is doing hundreds of these easy things at once, and keeping the whole thing maintainable. Or, to rephrase this in the present context: It's one thing to demonstrate a feature. It's a much more difficult thing to build that feature in a manner that supports integration, expansion, and long-term maintainability.
